One line. One resignation. One vending machine that still owes me change.

`main.ts` (Node 22, stdlib only, deterministic) writes the funniest
single-line resignation letter it can to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I resign, effective immediately — the vending machine ate my last dollar and my last shred of loyalty, and it still owes me change.

Run it:

```sh
node main.ts
```
